## 9. Открытые вопросы ТЗ → решения по умолчанию

Чтобы контракт не имел `TBD`, зафиксированы дефолты; при возражении заказчика меняется только `tenant_settings`/контракт, не архитектура.

| № ТЗ | Вопрос                 | Решение по умолчанию (MVP)                                                   |
| ---- | ---------------------- | ---------------------------------------------------------------------------- |
| 1    | Кто загружает оферту   | **Только `owner`** (`offers.manage`); админ — нет                            |
| 2    | Удаление лота          | **Только архив**; история аренд сохраняется                                  |
| 3    | Формат паспортных данных | Структурированные поля (серия, номер, кем выдан, дата, код подразделения) + **3 документа**: главная, регистрация, селфи |
| 4    | Хранение фото документов | 90 дней после решения (`verification_docs_retention_days`), затем purge-джоба + audit |
| 5    | N часов до напоминания | 1 ч по умолчанию, настраивается `owner` (`reminder_hours_before`)             |
| 6    | No-show                | Автостатуса нет: админ вручную отменяет/закрывает; в бэклог                   |
| 7    | Лимит обращений        | 5 в сутки на аренду, настраивается                                           |
| 8    | Просрочка > 24 ч       | Повторный алерт админу; блокировка пользователя — бэклог                     |
| 9    | Карта выдачи           | Нет (бэклог)                                                                 |
| 10   | Домен тенанта          | Поддомен `*.platform`; custom-domain через то же поле `domain` + DNS          |
| 11   | SaaS-оператор          | CLI-провижининг (`BE-TEN-02`), UI платформы — бэклог                         |
| 12   | Экспорт данных тенанта | Бэклог                                                                       |

**Дополнительное решение (в ТЗ не раскрыто):** модель `custom` = фиксированная цена за весь забронированный период (`fixed_price_minor` на лоте), без тарифной сетки. Тарифы — бэклог.

## 10. Риски и меры

| Риск | Влияние | Мера |
| ---- | ------- | ---- |
| SSR-кэш между тенантами | Утечка данных/брендинга | Ключ `host+path`, `useRequestHeaders(['cookie','host'])`, запрет общего кэша в BE-01/FE-01 |
| CORS с custom-доменами | Блокировка запросов/небезопасный `*` | `Access-Control-Allow-Origin` вычисляется из Host, `credentials=true`, тест в BE-QA-03 |
| Exclusion constraint + RLS | Ложные 409/500 | Маппинг `IntegrityError` в 409 `slot_taken`, тест на смежные интервалы |
| In-process rate limit | Не работает при > 1 инстанса API | Зафиксировать как ограничение MVP; Redis — бэклог, отмечено в CT-01 |
| iOS без PWA | Push не работает | FE-05 обязателен до P8; fallback email проверяется тестом |
| Мутация статусов без транзакции | Рассинхрон `rental`/`lot`/`occupancy` | Все переходы — в одной транзакции + audit; тесты гонок |
| Неопределённость модели `custom` | Неверный расчёт цены | Дефолт в §9, `contract/pricing.md`, подтверждение у заказчика до P5 |
| Отсутствие антивируса | Риск вредоносных файлов | Magic-bytes + приватный бакет; AV-хук как расширение (бэклог) |
