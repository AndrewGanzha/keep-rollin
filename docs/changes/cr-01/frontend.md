Правила проекта действуют без исключений: тонкие страницы, импорты только вниз (`pages → widgets → features → entities → shared`),
никакого `$fetch` в компонентах, форматирование — через `shared/lib`, Nuxt-композаблы вызываются до первого `await`,
только PrimeVue.

## FE-CAT-03 · Витрина «от»

**Зависит:** CT-10, MOCK-01. **Срез:** S1.

**Файлы:** `app/entities/lot/ui/LotCard.vue`, `app/widgets/lot-details/LotDetails.vue`, при необходимости
`app/shared/lib/money.ts` (формат «от X ₽/сут» + склонение «сутки/суток»).

**Объём:**

- Цена карточки — `lot.price_from`, не `lot.price_minor` (поля больше нет).
- Формат: `от 400 ₽/сут`; вторая строка — `при аренде от 7 суток, 1 АКБ` (показывается, только если `at_units > 1`
  или в лоте больше одного варианта).
- Карточка лота в каталоге показывает минимум по вариантам; выбор варианта живёт в диалоге брони (цена зависит от срока,
  которого на карточке ещё нет).

**AC:**

- [x] В `LotCard`/`LotDetails` нет арифметики по цене — только `price_from` и `formatMoney`.
- [x] При `at_units = 1` подпись не выводится (не дублируем «от 1 300 ₽/сут при аренде от 1 суток»).
- [x] На 320 px подпись укладывается максимум в две строки, карточка не растягивается по высоте.
- [x] Лот без вариантов в контракте (старый снапшот) не роняет страницу — пустая цена и `EmptyState`-заглушка.

**Проверка:** `pnpm dev:full` → каталог → все карточки с ценой; сеть не содержит запросов цены с клиента.

## FE-BOOK-04 · Бронь на quote, выбор варианта, сроки

**Зависит:** MOCK-01/CT-11 (сроки), MOCK-03 (ёмкость). **Замещает** `FE-BOOK-01` в части выбора периода и цены.
**Срез:** S1 (цена/вариант), S2 (сроки), S3 (ёмкость).

**Файлы:** `app/features/booking/create/model/booking.ts` (удалить `estimatePrice`, `durationOptions` строить из
`allowed_durations`), новый `app/features/booking/create/model/useQuote.ts`, `app/features/booking/create/ui/BookingDialog.vue`,
`app/features/booking/create/model/useCreateRental.ts`.

**Объём:**

1. `useQuote(lot, start, end)` — дебаунс 250 мс, отмена предыдущего запроса, `pending`/`error`, Nuxt-композаблы
   создаются до `await`.
2. Селектор варианта: `SelectButton` «1 АКБ / 2 АКБ» с ценой в подписи; недоступный вариант — `disabled` + причина
   из `unavailable_reason` (`battery_unavailable`, `slot_taken`).
3. Чипы сроков — из `lot.allowed_durations`; «Свой срок» с `min = min(allowed_durations)`, максимум — 365 или 90 для часовых.
4. Цена в диалоге — только из `quote`; `estimatePrice` удаляется вместе с тестами, которые его проверяют.
5. `POST /rentals` отправляет `variant_id`; обработка кодов: `slot_taken` → обновить quote, `battery_unavailable` →
   переключить на доступный вариант с тостом, `rental_period_not_allowed` → подсказка минимального срока.
6. Повторный клик блокируется `pending` (или `Idempotency-Key`, если он появится в контракте).

**AC:**

- [x] Цена не считается на клиенте ни в одном месте (grep по `price_minor` в `features/booking` пуст).
- [x] Смена варианта меняет цену без перезагрузки и без повторного выбора дат.
- [x] Недоступный вариант объяснён текстом, а не просто серой кнопкой. _Проверено в браузере: «2 АКБ — Свободных аккумуляторов на эти даты нет», вариант `disabled`._
- [x] При `allowed_durations = [7, 30]` чипов «1 день/3 дня» нет, «Свой срок» не даёт ввести меньше 7.
- [x] Двойной клик по «Забронировать» не создаёт две аренды. _Защита `pending` в `useCreateRental`; сценарий — в QA-BOOK-02._
- [x] Ошибка сервера показывается по `ApiError.code`, не по `detail`.

**Проверка:** сценарии S1/S2/S3 из [qa.md](qa.md) вручную + `tests/quote.test.ts`.

## FE-LOT-05 · Админ-форма: варианты, тиры, сроки, тип АКБ

**Зависит:** CT-10, CT-11, MOCK-01. **Срез:** S1 (варианты/тиры), S2 (сроки).

**Файлы:** `app/widgets/admin-lots/LotFormDialog.vue`, `app/features/admin-lots/model/useAdminLots.ts`
(добавить `save` для `POST`/`PATCH`), `app/widgets/admin-lots/AdminLotsTable.vue` (колонка «от», количество вариантов).

**Объём:**

- Редактор вариантов: строки «АКБ: 1 / 2», кнопка «+ вариант» (максимум 2 в MVP, контракт допускает больше).
- Таблица тиров на каждый вариант: `min_units` (1/3/7/30 из пресетов) и цена за единицу; подсказка «цена за сутки».
- Чекбоксы разрешённых сроков (1, 3, 7, 30, свой минимум); минимум списка = первая граница тиров.
- Поле типа АКБ (`48v`, `36v`, «без АКБ») — видно только при `battery_count > 0`.
- Режим правки: загрузка существующего лота в форму + `version`, `409 stale_version` → перечитать лот и показать тост.
- Валидация формы повторяет инварианты `decisions.md` (сортировка тиров, неубывающая цена, минимум тира = минимум сроков).

**AC:**

- [x] Нельзя сохранить растущую цену по сроку, пустой список сроков и тир ниже минимального срока.
- [x] Ошибка сервера подсвечивает поле (`fields` из problem+json), а не только тост.
- [x] Новый лот появляется в `GET /admin/lots` с `price_from` и попадает в каталог.
- [x] Правка тарифа существующего лота не меняет уже созданные аренды (их цена заморожена).

**Проверка:** создать лот с двумя вариантами → увидеть в каталоге «от» → отредактировать цену → повторно увидеть.

## FE-CAL-04 · Гант «лоты × дни»

**Зависит:** CT-11, MOCK-02, FE-LOT-05. **Замещает** `FE-CAL-02` и `FE-CAL-03`. **Срез:** S2.

**Файлы:** новый виджет `app/widgets/admin-schedule/` (`AdminScheduleGrid.vue`, `BlockDialog.vue`, `index.ts`),
`app/features/admin-schedule/model/useAdminSchedule.ts` (загрузка `schedule` + мутации блоков), `app/pages/admin/rentals.vue`
(переключатель «Дни месяца / Часы»), `app/shared/lib/calendar.ts` (дни месяца для ганта).

**Объём:**

- Сетка: sticky-колонка с названием лота, дальше дни месяца; шапка — числа и дни недели, выходные подсвечены.
- Полосы аренд по статусам (те же цвета, что в текущем календаре), выход за границы месяца обрезается стрелкой-индикатором.
- Блоки — штриховка/иконка замка, тултип с причиной.
- Выбор диапазона: клик по ячейке = один день, протяжка = несколько; открывается `BlockDialog` (причина, удаление).
- Клик по полосе аренды → существующий `AdminRentalDetails`.
- Часовой режим — существующий `AdminRentalsCalendar` без изменений, доступен переключателем; по умолчанию — дни месяца.
- На мобильном: горизонтальный скролл **внутри виджета**, страница не скроллится вбок; тач-таргет ячейки ≥ 44 px.

**AC:**

- [x] 30 дней × 20 лотов рисуются без горизонтального скролла страницы. _Проверено: 30 колонок × 6 seed-лотов, `scrollWidth - clientWidth = 0` страницы на 1280 и 375 px; прокрутка только внутри `.gant__scroll`. Ряды складываются вертикально, поэтому число лотов на ширину страницы не влияет._
- [x] Блокировка ставится за два клика и видна сразу, без F5.
- [x] Конфликт с арендой показывает текст `slot_taken`, а не «Ошибка».
- [x] Пустые лоты (без аренд) присутствуют в сетке.
- [x] Часовой таймлайн открывается тем же переключателем и не теряет фильтр статуса. _Проверено: «Просрочена» → «Часы» → обратно «Дни месяца», фильтр сохраняется._

**Проверка:** S2-сценарий из [qa.md](qa.md), включая мобильную ширину 375 px.
