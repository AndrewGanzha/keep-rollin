## 6.3.1. Платформа: каркас, API-слой, сессия, layout, UI-kit, PWA

_Подгруппа **F1** · 6 задач._

### FE-00 · Каркас Nuxt

**Зависит:** —
**Объём:** Nuxt 4, TS strict, ESLint, Nuxt UI, i18n (ru), структура `pages/{public,account,admin}`, `.env.example`, Dockerfile.
**AC:**
- [ ] `pnpm dev` и `pnpm build && node .output/server/index.mjs` работают.
- [ ] SSR отдаёт HTML с контентом (не пустой shell).
- [ ] Линт/типы зелёные в CI.

### FE-01 · API-слой

**Зависит:** FE-00, CT-04
**Объём:** обёртка над сгенерированным клиентом, `ApiError` из problem+json, маппинг `code`→i18n, авто-refresh по 401 (одна попытка), отмена запросов, проброс `host`/`cookie` в SSR; режим `NUXT_PUBLIC_API_MODE=mock|real` без изменения кода экранов.
**AC:**
- [ ] Ошибки backend отображаются по `code`, поля — по `fields`.
- [ ] 401 → refresh → повтор; при неудаче — редирект на логин.
- [ ] SSR-запросы несут cookie и `host`.
- [ ] Переключение mock → real — только переменными окружения; сборка не меняется.

### FE-02 · Сессия и начальная загрузка

**Зависит:** FE-01
**Объём:** Pinia-стор сессии, `GET /auth/session` при старте, logout, гидрация на клиенте после SSR.
**AC:**
- [ ] После F5 сессия восстанавливается без мигания гостевого UI.
- [ ] Logout очищает стор и cookie.

### FE-03 · Layouts, навигация, темизация

**Зависит:** FE-00, BE-TEN-01
**Объём:** `public`/`account`/`admin` layouts, мобильная нижняя навигация, брендинг из `/public/tenant` (CSS-переменные), favicon/title.
**AC:**
- [ ] Один и тот же билд показывает разные брендинги на разных Host.
- [ ] Навигация доступна с 320 px, тач-таргеты ≥ 44 px.

### FE-04 · UI-kit

**Зависит:** FE-00
**Объём:** `StatusBadge` (enum→цвет/текст), `DataTable` (серверная пагинация, пустые/загрузка), `FormField`, `DateRangePicker` (таймзона тенанта), `MoneyInput`, `ConfirmDialog`, `PhotoUploader`, `EmptyState`.
**AC:**
- [ ] Неизвестный enum рендерится как есть, без падения.
- [ ] Компоненты покрыты Vitest-тестами на граничные состояния.

### FE-05 · PWA-оболочка

**Зависит:** FE-00
**Объём:** manifest (per tenant), service worker, install-подсказка, offline-страница.
**AC:**
- [ ] Lighthouse: PWA-критерии установки выполнены.
- [ ] iOS Safari показывает «Добавить на экран» инструкцию.

## 6.3.2. Аутентификация, MFA, оферта

_Подгруппа **F2** · 6 задач._

### FE-AUTH-01 · Регистрация и логин

**Зависит:** FE-01, BE-AUTH-02, BE-OFF-01
**Объём:** `/login`, `/register`, чекбокс оферты со ссылкой, обработка `mfa_required`, ошибки по `code`.
**AC:**
- [ ] Клиентская валидация совпадает с серверной (zod из контракта).
- [ ] После регистрации — онбординг: оферта → верификация.
- [ ] 429 показывает таймер из `Retry-After`.

### FE-AUTH-02 · MFA UI

**Зависит:** FE-AUTH-01, BE-AUTH-03
**Объём:** экран ввода кода, enroll (QR, recovery-коды, подтверждение), повторная отправка недоступна.
**AC:**
- [ ] Recovery-код можно ввести вместо TOTP.
- [ ] QR и секрет доступны для ручного ввода.
- [ ] Коды восстановления скачиваются один раз.

### FE-AUTH-03 · Гварды и редиректы

**Зависит:** FE-02, BE-AUTH-04
**Объём:** middleware `auth`/`role`/`verified`; матрица редиректов (гость→логин, без верификации→верификация, без оферты→оферта, не та роль→403-страница).
**AC:**
- [ ] Прямой заход в `/admin/*` под `user` → 403, не пустой экран.
- [ ] Возврат на исходный URL после логина.
- [ ] SSR не отдаёт защищённую страницу без сессии (редирект 302).

### FE-AUTH-04 · Восстановление пароля

**Зависит:** FE-AUTH-01, BE-AUTH-05
**Объём:** `/password/forgot`, `/password/reset` (токен из query).
**AC:**
- [ ] Ответ не раскрывает существование email.
- [ ] Просроченный токен → понятная ошибка + ссылка на повтор.

### FE-OFF-01 · Принятие оферты

**Зависит:** FE-AUTH-03, BE-OFF-01
**Объём:** gate-компонент, просмотр текста, фиксация версии, блокировка брони без принятия.
**AC:**
- [ ] Новая версия оферты требует повторного принятия.
- [ ] 403 `offer_not_accepted` ведёт на экран принятия с возвратом.
- [ ] Принятие идемпотентно (двойной клик безопасен).

### FE-OFF-02 · Редактор оферты (owner)

**Зависит:** FE-04, BE-OFF-01
**Объём:** список версий, редактор (markdown + превью), публикация с подтверждением.
**AC:**
- [ ] Draft можно править, опубликованную — нет (только новая версия).
- [ ] Публикация показывает, какая версия станет неактивной.
- [ ] История версий с датами публикации.

## 6.3.11. E2E, a11y, бюджет производительности

_Подгруппа **F11** · 2 задачи._

### FE-QA-01 · E2E
