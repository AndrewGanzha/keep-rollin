# Контракт

## Статус

`openapi.json` — **seed-подмножество** контракта, собранное из §4 плана: публичный каталог, авторизация, аренды.
Он используется фронтендом для генерации типов и мок-сервера (`frontend/mock-server.config.ts`).

Источник правды переедет в Pydantic-модели backend на задаче **CT-03**; после этого файл экспортируется скриптом
`make openapi`, а расхождение с кодом падает в CI (CT-05).

## Артефакты

| Файл | Кто создаёт | Назначение |
| ---- | ----------- | ---------- |
| `openapi.json` | CT-03 (сейчас seed) | снапшот спецификации, вход для кодогенерации и мока |
| `decisions.md` | CT-01 | D-01…D-18, коды ошибок, enum-ы, лимиты |
| `endpoints.md` | CT-02 | сводная таблица операций и ролей |
| `analytics.md` | BE-AN-01 | формулы метрик и замеры |
| `pricing.md` | BE-BOOK-05 | правила расчёта цены |

План работ и обоснования — в `../docs/contract/`.
